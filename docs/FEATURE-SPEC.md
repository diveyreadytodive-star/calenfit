# 기능 명세

## 비로그인

- 히어로와 서비스 소개만 표시합니다.
- 히어로 CTA를 누르면 로그인 강제 없이 빈 월간 달력으로 이동합니다.
- 좌측 프로필 로그인 버튼, 일정 추가, Google 연결처럼 개인 저장이 필요한 행동에서 로그인 모달을 엽니다.
- 프로필·일정·정책 추천은 비어 있으며 시드 데이터를 복원하지 않습니다.

## 로그인과 온보딩

- 이메일 회원가입/로그인, Google 로그인, 로그아웃을 제공합니다.
- 회원가입 직후 빈 계정으로 시작합니다.
- 프로필이 없으면 좌측 프로필 온보딩을 표시합니다.
- 프로필에는 학교·전공·생활 목표를 포함합니다. 저장 뒤 입력 폼은 접히고 `프로필 수정` 버튼으로 다시 엽니다.
- Google OAuth 설정 안내는 일반 사용자 프로필에서 숨기고, 연결 해제는 연결된 사용자에게만 표시합니다. Secret은 입력받지 않습니다.
- 프로필 저장 후 해당 사용자의 정책 후보를 다시 계산합니다.

## 일정과 추천

- 중앙 월간 캘린더의 날짜 또는 `+ 일정 추가` 버튼으로 모달을 엽니다.
- 제목·날짜·설명을 저장하며 유형 선택 없이 자동 분류합니다.
- 서버가 반환한 일정 ID를 사용하고 새로고침·재로그인 후 복원합니다.
- 분류 유형·의도 태그·정책 분야는 일정 생성·수정 때 서버가 다시 계산하며 브라우저 입력값을 신뢰하지 않습니다.
- 직접 추가한 일정은 확인 모달을 거쳐 삭제할 수 있으며 연결 정책도 다시 계산합니다. Google 일정에는 `Google Calendar` 배지를 표시하고 삭제 버튼을 제공하지 않으며, 원본 캘린더에서 삭제한 변경을 다음 동기화에 반영합니다.
- 우측에는 일정 유형과 프로필에 연결된 정책 후보, 공식 URL, 확인할 조건과 증빙을 표시합니다.
- 각 정책은 출처 운영기관·마지막 확인 시각·불확실성을 표시하고, 타 지역 전용 정책은 거주지가 맞지 않으면 제외합니다.
- 현재 카탈로그 밖 입력에는 온통청년·정부24 혜택알리미·복지로·고용24·지역 청년포털을 펼쳐보는 공식 출처 패널을 제공합니다.
- 학교명이 입력되면 학교·학과 공식 공지 탐색 링크를 추가합니다. 이는 실시간 수집 성공이나 자격 확인으로 표시하지 않습니다.
- 우측의 미니 달력 대신 일정 기반 정책을 표시하고, 별도 박스에는 일정이 없어도 프로필로 찾은 일반 정책을 표시합니다.
- 동일 정책에 여러 일정이 연결되면 정책 카드는 하나만 표시하고 연결 일정명을 묶어 보여줍니다.
- 자취방·월세·임대차 계약은 청년월세지원, 근로장려금 일정은 국세청 근로장려금 후보 규칙으로 연결합니다.
- 수영·운동·체육 수업은 튼튼머니와 문화누리카드 후보를 연결하며, 스포츠강좌이용권처럼 연령이 맞지 않는 정책은 프로필 출생연도로 제외합니다.
- 중앙 월간 달력은 좌우 화살표로 이전·다음 달을 탐색합니다.

## Google Calendar

- 로그인 사용자만 연결할 수 있습니다.
- OAuth 자격증명이 없으면 명시적으로 서버 설정 필요를 표시합니다.
- 연결 성공 후 서버가 일정을 normalize/upsert하고 월간 달력에 표시합니다.
- 우측 상단 상태 표시에서 연결됨·동기화 중·미연결·설정 필요·오류를 구분합니다.
- 브라우저 탭이 열려 있으면 5분마다 증분 동기화하고, 탭 복귀 시 마지막 동기화가 5분 이상 지났으면 즉시 갱신합니다. 백그라운드 webhook 동기화는 운영 확장 범위입니다.
- token은 브라우저에 반환하지 않습니다.

## AI

- `/api/ai/analyze`가 서버에서 Groq를 호출합니다.
- Groq가 일정 유형과 함께 의도 태그·정책 분야를 추출하고, 규칙 엔진이 해당 분야를 공식 정책 카탈로그에 연결합니다.
- 프로필의 학교·전공·현재 상태·생활 목표도 제한된 분야 태그로 분석해 일정이 없는 추천에 사용합니다.
- 주거·실직·일경험·장학·자산형성·결혼·출산·육아·문화·마음건강 신호를 전국 및 지역 공식 정책 후보에 연결합니다.
- 직접 추가 일정과 Google 동기화 일정을 모두 분석하며 키워드 사전은 AI 실패 시 fallback으로만 사용합니다.
- 키 미설정·timeout·잘못된 응답이면 로컬 분류로 계속 동작합니다.
- rate limit은 `GROQ_RATE_LIMITED`로 구분하며 상태등은 단순 키 존재가 아니라 Groq 모델 API 도달 여부를 검사합니다.
- AI는 정책 수급 여부나 금융상품 가입을 결정하지 않습니다.

카카오 로그인·카카오 알림톡·실제 SMS/푸시 발송은 후속 구현 예정입니다.

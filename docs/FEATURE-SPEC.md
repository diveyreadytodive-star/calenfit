# 캘린핏 기능 명세

## 입력 → 판단 → 안내 → 기록

| 단계 | 제품 동작 | 사용자에게 보이는 것 |
| --- | --- | --- |
| 입력 | 수동 일정 제목·날짜·설명·유형, `.ics` 파일 선택, 증빙 파일 선택 | 입력 폼의 목적과 로컬 처리 범위 |
| 판단 | 제목·설명 기반 결정론적 분류, 프로필과 이벤트를 명시 규칙에 대입 | 면접/시험 유형, 신뢰도, `가능성 높음`·`확인 필요`·`현재 대상 아님` |
| 안내 | 정책 조건, D-3/D+1/D+3 행동, 복구 가능한 대체 증빙 제공 | 다음 행동, 공식 신청 링크, 운영기관 최종 판단 고지 |
| 기록 | `localStorage`에 이벤트 CRUD, 태스크 완료, 복구 체크, 정책 상태, 파일 메타데이터 연결 | 새로고침 후에도 유지되는 사건별 타임라인과 증빙 보관함 |

## 브라우저 데모 절차

1. `python3 -m http.server 8000` 실행 후 `http://localhost:8000/` 접속.
2. 기본 가상 면접 일정을 선택하고 정책 카드·공식 출처·D-3/D+1/D+3 행동을 확인.
3. 사건 상세에서 제목·날짜·설명을 수정하거나 삭제 확인을 거쳐 제거.
4. 복구 모드의 면접확인서·대체 증빙을 체크하고, 요청 메일 초안 복사를 시도.
5. 이미지/PDF 증빙을 선택해 파일 메타데이터와 파일명 힌트를 확인. 원본은 저장하지 않음.
6. 유효한 `.ics` 파일을 선택하고 미리보기의 `가져오기 확인`으로 일정을 추가. 잘못된 컨테이너·날짜·필드에는 이해 가능한 오류 표시.
7. 정책 상태를 네 가지 값으로 전환해 신청 CTA의 활성/비활성 상태를 확인하고, 새로고침 후 유지되는지 확인. `데모 초기화`로 종료.

## MVP 정책

- 경기도 청년 면접수당: 경기도 거주·미취업·면접 참여 증빙을 명시 조건으로 표시합니다.
- 경기청년 역량강화 기회지원: 경기도 거주·대상 시험·응시 사실·영수증을 확인 대상으로 표시합니다.
- 공식 URL과 `checkedAt`을 각 카드에 노출합니다. 마감·예산 소진·상태 확인 필요를 신청 가능으로 추정하지 않습니다.

## AI 사용 지점과 안전 경계

현재 데모는 API 키 없이 동작하는 로컬 분류기를 사용합니다. 향후 LLM 어댑터를 연결할 수 있지만, 입력은 제목·설명으로 제한하고 결과는 사용자가 확인·수정할 수 있는 후보로만 취급합니다. 정책 매칭과 자격 가능성은 명시적 규칙 엔진이 계산하며 AI가 최종 수급 자격, 예산 소진, 정책 유효성을 결정하지 않습니다.

증빙 분석은 파일 원본을 외부로 보내지 않는 브라우저 데모 범위에서 파일명·유형·크기·수정 시각과 간단한 힌트만 기록합니다. 실제 서비스에서는 최소 권한, 암호화, 삭제, 동의 범위를 별도로 설계해야 합니다.

## 제외 범위

전국 정책 자동 크롤링, Google Calendar/Gmail OAuth, 정부24·잡아바 자동 신청, 실제 메일 발송, OCR/문서 원문 전송, 마이데이터, 다중 사용자 계정, 금융상품 추천은 MVP에 포함하지 않습니다. ICS는 정적 파일을 브라우저에서 파싱·미리보기·확정 가져오기만 하며 외부 캘린더 동기화는 제공하지 않습니다.

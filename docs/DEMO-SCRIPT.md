# 심사 시연 순서

1. 첫 접속에서 히어로만 보이고 프로필·일정·정책이 노출되지 않는 것을 확인합니다.
2. `내 일정에서 혜택 찾기`를 눌러 로그인 없이 빈 월간 캘린더를 둘러봅니다.
3. 좌측 `로그인 필요`를 눌러 인증 모달을 열고 새 이메일로 회원가입한 뒤 프로필 온보딩을 확인합니다.
4. 출생연도·거주지·상태·학력·목표를 저장합니다.
5. 9월의 날짜를 누르고 시험 또는 면접 일정을 추가합니다.
6. 일정이 해당 날짜 칸과 다가오는 일정에 표시되고, 우측 정책·할 일이 갱신되는 것을 확인합니다.
7. 새로고침 후 같은 프로필과 일정이 유지되는 것을 확인합니다.
8. Google Calendar 연결을 누릅니다. 자격증명이 설정된 환경에서는 Google 동의 후 돌아와 일정이 동기화됩니다. 미설정 환경에서는 정확한 설정 필요 오류가 표시됩니다.
9. 로그아웃하면 개인 데이터가 즉시 사라지고, 재로그인하면 해당 계정 데이터만 복원됩니다.

AI와 정책 규칙은 후보를 제시할 뿐 최종 자격·금액·예산·신청 가능 여부를 확정하지 않는다고 설명합니다.

# Calenfit Challenge Demo Script

1. 로그인 없이 랜딩에서 “AI가 내 일정을 읽고, 받을 혜택을 찾습니다.”와 로직 맵 안전 고지를 보여준다.
2. 데모를 시작해 2026년 9월 월간 캘린더의 가상 면접·시험 일정을 확인한다.
3. 9월 4일 면접을 선택해 AI/로컬 fallback 분류, 정책 후보, 공식 URL·확인 시각·운영기관 최종 판단을 보여준다.
4. 면접확인서 없음을 선택하고 안내 이메일·채용공고를 대체 증빙으로 체크한 뒤 요청 초안을 복사한다.
5. 정책 상태를 접수 중→마감→예산 소진→확인 필요로 바꿔 CTA가 신청을 가장하지 않는지 보여준다.
6. 자체 캘린더에 가상 시험을 추가하고 영수증·응시 사실 task 및 새로고침 지속을 보여준다.
7. 일정 연결에서 자체/ICS/Google 상태를 비교하고 Google 성공·권한 거부 mock이 실제 OAuth가 아님을 말한다.
8. 알림에서 웹 동의 예약 payload와 SMS/Kakao credential·동의 차단 사유를 outbox로 보여준다.

마무리: “캘린핏은 금융 판단을 대신하지 않고, 일정에서 놓치기 쉬운 증빙 행동을 공식 기준 확인과 연결합니다.”
